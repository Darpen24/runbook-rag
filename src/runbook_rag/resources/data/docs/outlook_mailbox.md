# Outlook and the mailbox

## Mailbox size
Each mailbox has 50 GB of space. Outlook warns at 45 GB. Empty the Deleted Items and Junk Email folders first. Move old messages to the online archive, which has no size limit for normal use.

## New mail does not arrive
Check whether Outlook is in offline mode. On the Send and Receive tab, offline mode is shown as a highlighted button. Switch it off and wait five minutes. If the problem stays, restart Outlook and check that the internet connection works.

## Out of office
Open File and choose Automatic replies. Set the start and end date and write one message for colleagues and one for external senders. Replies are sent once per sender.

## Shared mailboxes
Ask the owner of the shared mailbox to request access for you. After approval it appears in Outlook within an hour. Do not add it by hand.
