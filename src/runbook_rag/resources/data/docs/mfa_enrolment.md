# Multi factor authentication

## Why we use it
Multi factor authentication adds a second step after the password. Even if a password is stolen, nobody can sign in without the second factor.

## Setting up the authenticator app
Sign in to the security info page with the work account. Choose "Add method" and select the authenticator app. Scan the QR code with the phone camera and enter the six digit code to finish. The setup takes about three minutes.

## Getting a new phone
Set up the app on the new phone first while the old phone still works. Then remove the old phone from the list of methods. If the old phone is already lost or broken, the service desk must verify your identity before the second factor can be reset.

## Lost phone
Report a lost phone to the service desk right away. The sessions of the lost device are ended and a temporary access code valid for one day is issued after identity verification.
