# VPN setup and troubleshooting

## Installing the VPN client
Install the VPN client from the company software portal. Search for "Secure VPN" and select Install. The client needs administrator approval only the first time. After the installation, restart the laptop.

## Connecting from home
Open the VPN client and choose the profile "Company Remote". Sign in with the work account and approve the request in the authenticator app. The status changes to Connected within about ten seconds. Keep the client open while you work with internal systems.

## When the VPN does not connect
First check that the home internet works by opening a public web page. Close the client completely and start it again. If the client is more than one version behind, install the newest version from the software portal. Error code 809 usually means a router blocks the connection, so try a mobile hotspot. If the same error appears on two networks, write down the error code and contact the network team.

## Split tunnelling
Only traffic to internal systems goes through the VPN. Video calls and public web pages use the normal home connection to save bandwidth.
